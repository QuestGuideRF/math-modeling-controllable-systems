# 🔬 Математическое моделирование управляемых систем

Веб-сервис для математического моделирования и анализа управляемых систем, предоставляющий инструменты для расчета алгебраических критериев и решения систем дифференциальных уравнений.

![Скриншот сервиса](service.png)

## 📋 Описание проекта

Проект представляет собой веб-приложение для выполнения сложных математических вычислений в области теории управления. Сервис реализует:

- **Калькулятор алгебраических критериев** — расчет различных критериев устойчивости для систем управления
- **Решение систем дифференциальных уравнений** — численное и аналитическое решение ДУ с поддержкой символьных вычислений
- **Генерация графиков** — автоматическое построение годографов и визуализация результатов вычислений

### ✨ Особенности

- ⚡ Вычисление критериев, введённых через текстовое поле
- 🎨 Генерация графиков на лету в формате PNG
- 📱 Адаптивный дизайн для мобильных устройств
- 🔄 Гибкая архитектура с возможностью переиспользования компонентов

## 🛠️ Технологический стек

- **Backend**: Python 3 (HTTP-сервер на базе стандартной библиотеки)
- **Математические библиотеки**:
  - `numpy` — численные вычисления
  - `sympy` — символьные вычисления
  - `matplotlib` — построение графиков
  - `texttable` — форматирование таблиц
- **Frontend**: HTML, CSS, JavaScript
- **Веб-сервер**: Nginx (для статических файлов и проксирования)
- **Системный сервис**: systemd (для автозапуска)

## 📦 Установка зависимостей

### Системные зависимости

Установите Python 3 и pip (если они еще не установлены):

```bash
sudo apt install python3-pip
```

Установите пакет `psmisc` (для утилиты `fuser`, которая освобождает занятые порты):

```bash
sudo apt install psmisc
```

Установите Nginx:

```bash
sudo apt install nginx
```

### Python-зависимости

Установите необходимые Python-пакеты:

```bash
sudo pip3 install numpy
sudo pip3 install texttable
sudo pip3 install matplotlib
sudo pip3 install sympy
```

> **Примечание**: `texttable` указан дважды в оригинальной инструкции, достаточно установить один раз.

## 🚀 Использование

### Быстрый запуск для тестирования

Для единичного запуска и тестирования используйте скрипт:

```bash
./test
```

Этот скрипт:
- Освобождает занятый порт для демона калькулятора
- Проверяет актуальность репозитория (необходимо для предотвращения конфликтов)
- Запускает тестовую версию сервера на порту `6667`

### Развертывание на сервере

Проект предполагает наличие двух окружений:
- **Продакшен** — стабильная версия, изменения только через git
- **Тестинг** — окружение для разработки и проверки изменений

#### Предварительные настройки

1. **Отключите стандартное прослушивание порта 80 в Nginx:**

   В файле `/etc/nginx/sites-enabled/default` замените `80` на неиспользуемый порт (например, `79`):

   ```nginx
   server {
       listen 79 default_server;
       listen [::]:79 default_server;
       ...
   }
   ```

2. **Добавьте конфигурации для сервера:**

   В файле `/etc/nginx/nginx.conf` добавьте строки внутри блока `http`:

   ```nginx
   include <absolute path to production>/conf/prod.nginx.conf;
   include <absolute path to testing>/conf/test.nginx.conf;
   ```

3. **Настройте пути в конфигурациях:**

   В файле `conf/prod.nginx.conf` укажите абсолютный путь:

   ```nginx
   root <абсолютный путь до папки www в репозитории>;
   ```

4. **Настройте права доступа:**

   В файле `/etc/nginx/nginx.conf` в начале файла замените:

   ```nginx
   user root;
   ```

   > ⚠️ **Внимание**: В продакшене рекомендуется добавить `root` в группу `www-data` вместо изменения пользователя.

5. **Настройте systemd-демон:**

   - В файле `conf/mydaemon.service` замените `<absolute_path>` на абсолютный путь к продакшен-папке репозитория
   - Скопируйте файл в системную директорию:

   ```bash
   sudo cp conf/mydaemon.service /etc/systemd/system/
   sudo systemctl daemon-reload
   ```

#### Деплой в продакшен

Для развертывания обновлений используйте скрипт:

```bash
./deploy
```

Скрипт выполняет:
- Отмену всех локальных изменений (`git reset --hard`)
- Обновление кода из репозитория (`git pull`)
- Перезагрузку конфигурации Nginx
- Перезапуск демона
- Проверку работоспособности через curl
- Вывод статуса службы

#### Управление сервисом

Доступны вспомогательные скрипты для управления:

- `./start` — запуск демона
- `./stop` — остановка демона
- `./status` — проверка статуса демона
- `./reload_nginx` — перезагрузка конфигурации Nginx

## 🔧 Архитектура

- **`print_server.py`** — переиспользуемая библиотека для хостинга Python-скриптов в виде HTTP-сервера. Выводит в браузер весь вывод скрипта и обрабатывает исключения.
- **`criterions_server.py`** — основной сервер, обрабатывающий запросы:
  - `/calc_criterion/<параметры>` — расчет критериев с текстовым выводом
  - `/calc_criterion_png/<параметры>` — генерация графика годографа
  - `/calc_diffur/<параметры>` — решение системы дифференциальных уравнений
- **Статические файлы** обслуживаются через Nginx с поддержкой SSI (Server Side Includes)
